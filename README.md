Fitness AI

An AI-powered fitness and nutrition coaching application that generates personalized workout plans, meal plans, calorie targets, macro recommendations, and health insights based on user goals and fitness profiles.

Features
- BMI Calculator
- BMR Calculator
- TDEE Calculator
- Goal-based Calorie Planning
- Macro Calculation
- Water Intake Recommendation
- Workout Generator
- Meal Planner

Tech Stack
- Python
- Git
- GitHub
